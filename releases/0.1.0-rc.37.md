## 安装

1. 下载 `.dmg`，打开后把 bots 拖进「应用程序」（或下载 `.zip` 解压后拖进去）。
2. 首次打开（二选一）：
   - 在 Finder 的「应用程序」里**右键** bots →「打开」→ 在弹窗里再点「打开」；
   - 或在终端去掉隔离属性后正常双击：

     ```bash
     xattr -dr com.apple.quarantine /Applications/bots.app
     ```

之后正常双击即可。只对从本页下载、校验和对得上的包这样做。
